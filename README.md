# YouTube Homepage Clone

A static front-end recreation of a YouTube homepage. It uses HTML and CSS to display a video grid, thumbnails, channel pictures, and a styled header with search and profile controls.

## Features

- YouTube-inspired header with search and voice search controls
- Video grid with thumbnails, titles, channel names, view counts, and upload dates
- Video duration labels
- Sidebar area
- Roboto font loaded from Google Fonts
